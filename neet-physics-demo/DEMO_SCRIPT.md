# Orbit Physics — 7-Minute Demo Script

## 1. Open with the academic problem — 30 seconds

“Most learning platforms show content and scores. Orbit closes the complete loop: learn, test, analyse, correct and continue.”

## 2. Student login — 30 seconds

Use:

- `student@physics.local`
- `student123`

Point out:

- Current lesson
- Daily test due
- Unresolved errors
- Full 138-lecture schedule

## 3. Learning path — 45 seconds

Open **Learning path**.

Explain:

- Mathematical Tools and Units are available in the demo.
- All remaining Class 11 chapters are visible as a locked full-year roadmap.
- New theory finishes in December; January is protected for revision.

## 4. Lesson experience — 90 seconds

Open **Trigonometry & Graph Interpretation**.

Show:

- Recall strip
- Common, CBSE and NEET emphasis tags
- Concept → example → exam-trap structure
- Selecting text and saving a note

## 5. Daily test — 90 seconds

Start the five-question test.

Explain:

- Test takes 10–15 minutes after class.
- Results are stored by question and topic.
- A score below 70% creates remediation instead of blocking learning permanently.
- Incorrect questions enter the 48-hour error log.

Submit the test and show explanations.

## 6. Error log and notebook — 45 seconds

Show:

- Wrong answer
- Correct answer and explanation
- Topic and lesson
- Retry status
- Saved notes grouped by learning purpose

## 7. Teacher login — 90 seconds

Sign out and use:

- `teacher@physics.local`
- `teacher123`

Show:

- Next-day review queue
- Question miss rate
- Weakest topics
- Recent attempts
- Individual student mastery and complete attempt history

Explain:

“Before starting the next topic, the teacher knows exactly which misconceptions require a 5–10 minute review.”

## 8. Close — 15 seconds

“This demo is fully local. The same validated academic flow can later move to cloud authentication and multi-student deployment without changing the learning design.”
